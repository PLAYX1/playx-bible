# PLAY X 번역 — 라이선스와 출처

> 상태: **확정** (2026-07-28). 신·구약 전권이 원문 기반 재번역으로 완료되어
> 본문 전체가 아래 라이선스의 적용 대상이다.

## 왜 여는가

성경 번역의 역사는 곧 탈중앙화의 역사다. 틴들은 "쟁기질하는 소년도 성경을 알게 하겠다"며
영어로 옮기다 처형당했고, 루터의 독일어 성경과 한국의 개역한글도 같은 흐름 위에 있다.
지금도 BSB(Berean Standard Bible)가 2023년 저작권을 퍼블릭 도메인으로 헌정했고,
WEB은 아예 저작권 없이 만들어졌으며, ebible.org와 open-bibles가 그 뒤를 잇고 있다.

PLAY X 번역은 그 흐름에 합류한다. **말씀에는 값을 매기지 않는다. 말씀을 섬기는 노동
(도구·운영·창작·인쇄)에 값을 매긴다.**

## 층위별 라이선스

말씀 본문은 열되, 그 위에 쌓은 창작물과 브랜드는 구분한다.

| 대상 | 라이선스 | 뜻 |
|---|---|---|
| **PLAY X 번역 본문** (절 텍스트) | **CC BY 4.0** | 누구나 복제·수정·상업적 이용 가능. 출처 표시만 의무. |
| 원어 노트·인터리니어·해설 | 저작권 유지 | PLAY X의 고유 편집 자산. |
| 통독 커리큘럼·묵상 콘텐츠 | 저작권 유지 | 창작물. |
| "PLAY X" 이름·로고 | 상표 | 본문 공개가 브랜드 공개는 아니다. |
| 정본 저장소 | PLAY X 관리 | 리눅스 모델 — 누구나 복제하되 정본은 공개 검증으로 정한다. |

### 출처 표시 형식

```
PLAY X 번역(플레이엑스) · 번역: 김무송 · CC BY 4.0
```

한국 저작권법상 성명표시권은 양도되지 않는다. 본문을 자유롭게 쓰더라도 이 표시를
지우고 배포하는 것은 라이선스 위반이자 저작인격권 침해다.

## 범위 — 어느 절이 공개 대상인가

**신·구약 66권 전권**이 원문(WLC 히브리어 / SBLGNT 그리스어) 기반으로 번역되어
본문 전체가 CC BY 4.0 적용 대상이다(2026-07-28 완료).

품질 게이트는 모든 절에 대해 ① 기존 저작권 역본과의 유사 문장 차단(유사도 게이트)
② 문체 게이트 ③ 원문 대조 감사(구조 왜곡·신학적 구분 소실·지시 대상 오류)를 수행했다.
짧은 정형구·족보처럼 표현이 수렴할 수밖에 없는 절은 사유와 함께
`verification/accepted_exceptions.json` 에 공개한다(검증의 공개).

## 검증의 공개

"누가 승인했는가"가 아니라 "근거가 공개되어 있는가"로 신뢰를 만든다.

- 번역 수정 이력은 git 히스토리로 남는다.
- 절별 원문 근거는 앱의 인터리니어에서 대조할 수 있다.
- 정정 제보는 GitHub Issues 또는 앱 내 의견 제출로 받는다.
- 오탈자·오역 수정은 정본 저장소에 반영하고 사유를 커밋 메시지에 남긴다.

## 하지 않는 것

- 본문 열람·검색·비교·원문 대조에 과금하지 않는다.
- 특정 교단·기관의 교리 승인을 정본의 조건으로 두지 않는다.
- 이단 계열 자료를 저본으로 삼지 않는다. 본문은 공인된 비평본과 공개 저장소에서만 가져온다.
