# PLAY X 성경 (PLAY X Bible)

한국어 신·구약 66권 전권 번역. 히브리어(WLC)·그리스어 원문에서 현대 한국어로 새로 옮긴
역본이며, 본문 전체를 **CC BY 4.0**으로 공개한다.

> 말씀에는 값을 매기지 않는다. 말씀을 섬기는 노동에 값을 매긴다.

- **번역·발행**: PLAY X · 김무송
- **본문 라이선스**: [CC BY 4.0](LICENSE) — 복제·수정·상업적 이용 자유, 출처 표시 의무
- **출처 표시 형식**: `PLAY X 번역(플레이엑스) · 번역: 김무송 · CC BY 4.0`
- **읽는 곳**: https://gods-voice.ex.erci.se

## 왜 이 번역을 열었는가

이 번역은 한 사람의 질문에서 시작됐다. 성경을 읽다 보면 원문과 조금 다르게
옮겨진 듯한 대목들을 만난다 — 옛 번역이 틀렸다는 뜻이 아니다. 그 시대의 언어로는
그 해석이 옳았을 것이다. 다만 그 말과 지금 우리가 쓰는 말 사이에 세월만큼의
거리가 생겼고, 번역자는 그 거리를 직접 확인하고 이해하고 싶었다. 그래서 히브리어·
그리스어 원문으로 돌아가, 지금의 언어로 신·구약 66권 전권을 다시 옮겼다.

성경 번역의 역사는 늘 그렇게 이어져 왔다. 틴들은 "쟁기질하는 소년도 성경을
알게 하겠다"며 영어로 옮겼고, 루터의 독일어 성경과 한국의 개역한글(1961)이 그
흐름을 이었다. 개역한글 이후 65년 — 한국어에는 자유롭게 쓸 수 있는 현대어 성경이
아직 없다. 같은 질문을 가진 누구든 자유롭게 읽고 쓰고 고칠 수 있도록, 이 번역
전부를 CC BY 4.0으로 헌정한다.

**말씀에는 값을 매기지 않는다. 말씀을 섬기는 노동에 값을 매긴다.** 본문은 누구의
것도 아니되, 검증과 교정의 책임은 번역자의 이름으로 진다.

## 번역 원칙

1. **원문 우선.** 히브리어 마소라 본문(WLC)·그리스어 원문을 1차 기준으로 삼았다.
   사본 이문이 익숙한 번역과 다르면 원문을 따랐다(예: 막 1:41 ὀργισθείς "분노하시어").
2. **현대 한국어.** 고어체(~니라/~로다)를 쓰지 않는다. 인용문의 어투는 화자와 청자의
   관계를 따른다(사람→하나님 존댓말, 하나님→사람 평어).
3. **절 단위 완결.** 여러 절에 걸친 발언은 절마다 따옴표를 닫고 연다 — 절 단위로
   읽히는 화면을 위한 규칙이다.
4. **다층 검증.** 모든 절이 삼중 검증을 거쳤다 — (a) 저작권 유사도 검사: 기존
   저작권 역본과 유사한 문장 차단 (b) 문체 일관성 검사 (c) 원문 대조 감사(구조
   왜곡·신학적 구분 소실·지시 대상 오류 3유형). 감사는 공개 후에도 계속되며,
   교정 이력은 이 저장소에 그대로 남는다.

## 검증의 공개

짧은 정형구·족보처럼 자연스러운 한국어가 사실상 하나뿐인 절은 기존 역본과 표현이
수렴할 수 있다. 그런 절은 억지로 비틀지 않고 **사유와 함께 예외 목록에 기록**했다
(`verification/accepted_exceptions.json`). 존댓말 사용이 정당하다고 판정된 절 목록도
같이 공개한다(`verification/style_exceptions.json`). 누구나 검토하고 이의를 제기할 수 있다.

## 개발자용 데이터 접근

별도 API 없이 이 저장소를 그대로 쓰면 된다(트래픽 무료):

```
# CDN (jsDelivr) — 책별
https://cdn.jsdelivr.net/gh/PLAYX1/playx-bible@main/books/창.json

# GitHub raw — 전권
https://raw.githubusercontent.com/PLAYX1/playx-bible/main/verses/playx-bible.json
```

형식은 `{"창1:1": "본문", ...}` 이므로 `data["요3:16"]` 한 줄로 절을 꺼낼 수 있다.
활용 조건은 LICENSE(CC BY 4.0 — 출처 표시)를 따른다. 절 단위 REST API가
필요하면 Issues로 요청해 달라 — 수요가 확인되면 제공을 검토한다.
